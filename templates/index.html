Python demo with MS Entra ID SSO

This sample supports two sign-in modes on one site: Flask/MSAL (app-managed) and App Service Easy Auth (platform-managed).

MSAL Mode

The Flask app uses MSAL to initiate sign-in, process the authorization response, acquire tokens, and maintain the authenticated user session in application code.

Sign in with MSAL

Easy Auth Mode

Azure App Service authenticates the user before the request reaches Flask, then provides verified identity details through platform-managed headers.
